## Azure CLI repair

The Homebrew Azure CLI 2.85.0 Python runtime failed when importing `pyexpat` because the module expected `_XML_SetAllocTrackerActivationThreshold`, which the system `libexpat` did not export. Updating Azure CLI alone reproduced the problem with its new Python 3.14 runtime.

Repair commands:

```bash
brew upgrade azure-cli
brew install expat
install_name_tool -change \
  /usr/lib/libexpat.1.dylib \
  /opt/homebrew/opt/expat/lib/libexpat.1.dylib \
  /opt/homebrew/Cellar/python@3.14/3.14.6/Frameworks/Python.framework/Versions/3.14/lib/python3.14/lib-dynload/pyexpat.cpython-314-darwin.so
codesign --force --sign - \
  /opt/homebrew/Cellar/python@3.14/3.14.6/Frameworks/Python.framework/Versions/3.14/lib/python3.14/lib-dynload/pyexpat.cpython-314-darwin.so
```

Verification:

```bash
az version
az account show
az storage account list
```

All three commands completed successfully with Azure CLI 2.88.0. Blob data-plane parsing now works; account-level network policy still correctly blocks access to `aariqstorage0426`.
